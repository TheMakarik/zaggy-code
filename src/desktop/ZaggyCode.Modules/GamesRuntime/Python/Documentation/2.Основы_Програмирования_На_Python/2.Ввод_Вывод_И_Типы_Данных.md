# Ввод, вывод и типы данных

## Введение

После того как мы разобрались с историей и философией Python, самое время перейти к практике. В этой статье мы рассмотрим самые основы — то, с чего начинается знакомство с любым языком программирования. Мы научимся выводить информацию на экран, получать данные от пользователя и разберемся, какие типы данных существуют в Python.

## Комментарии в коде

Прежде чем мы начнем изучать основные конструкции, давайте поговорим о комментариях. Комментарии — это текст в коде, который Python игнорирует при выполнении программы. Они нужны для того, чтобы программист мог оставлять пояснения к своему коду — для себя или для других разработчиков, которые будут читать этот код в будущем.

В Python комментарии начинаются с символа `#` (решетка). Всё, что написано после этого символа на той же строке, считается комментарием и не выполняется:

```python
# Это комментарий. Python его проигнорирует.
print("Hello, World!")  # А это комментарий после кода
```

Комментарии бывают очень полезными. Представьте, что вы написали сложную программу, а через полгода вернулись к ней и забыли, что и зачем вы писали. Комментарии помогут вам вспомнить логику. Также комментарии используют, чтобы временно "выключить" часть кода во время отладки:

```python
# print("Эта строка не выполнится")
print("А эта выполнится")
```

Есть еще многострочные комментарии. В Python для них нет отдельного синтаксиса, но обычно используют тройные кавычки — либо одинарные, либо двойные. Такой текст не присваивается переменной и не выполняется, но технически это строка-документация (докстринг), которую можно использовать для больших пояснений:

```python
"""
Это многострочный комментарий.
Он может занимать несколько строк.
Python его проигнорирует.
"""
print("Код продолжает работать")
```

Хороший код — это код с понятными комментариями. Но не переусердствуйте: комментарии должны объяснять "почему", а не "что". Что делает код — видно из самого кода.

## Вывод данных: функция print()

Самая первая и самая простая вещь, которую вы научитесь делать в Python — это выводить текст на экран. Для этого используется встроенная функция `print()`.

Как это работает? Вы просто пишете слово `print`, ставите круглые скобки, а внутри них — то, что хотите показать:

```python
print("Hello, World!")  # Выводит текст в консоль
```

Когда вы запустите этот код, в консоли появится текст:

```
Hello, World!
```

Внутри скобок можно указывать не только текст. Можно выводить числа:

```python
print(42)  # Выводит число
```

Можно выводить несколько вещей сразу, перечисляя их через запятую:

```python
print("I am", 25, "years old")  # Выводит: I am 25 years old
```

Python сам добавит пробелы между частями. Если вы хотите изменить этот пробел на что-то другое, используйте параметр `sep` (сокращение от "separator" — разделитель):

```python
print("Apple", "Banana", "Orange", sep=", ")  # Выводит: Apple, Banana, Orange
```

По умолчанию `print()` после вывода переводит курсор на новую строку. Если вам нужно вывести несколько сообщений в одну строку, используйте параметр `end`:

```python
print("Loading", end="... ")  # Выводит без перевода строки
print("Done!")  # Выводит: Loading... Done!
```

## Ввод данных: функция input()

Чтобы программа могла общаться с пользователем не только в одну сторону, существует функция `input()`. Она позволяет получить текст, который введет пользователь с клавиатуры.

Работает это просто: программа останавливается и ждет, пока пользователь что-нибудь напечатает и нажмет Enter. Все, что ввел пользователь, сохраняется в переменную:

```python
name = input()  # Программа ждет ввода
print("Hello,", name)  # Выводит приветствие
```

Если вы запустите этот код, программа будет ждать ввода. Вы напечатаете свое имя, нажмете Enter, и программа поприветствует вас.

Чтобы пользователь понимал, что от него требуется, можно передать подсказку прямо в `input()`:

```python
name = input("What is your name? ")  # Показывает вопрос перед вводом
print("Hello,", name)  # Выводит приветствие
```

Теперь программа сначала покажет вопрос, а уже потом будет ждать ввода.

**Важно:** функция `input()` всегда возвращает текст (строку). Даже если пользователь ввел число, Python воспримет его как текст:

```python
age = input("How old are you? ")  # Всегда возвращает строку
print(age + 10)  # Ошибка! Нельзя сложить строку и число
```

Этот код вызовет ошибку, потому что нельзя сложить текст и число. Как с этим работать, мы разберем чуть позже, когда познакомимся с преобразованием типов.

## Типы данных

В Python всё имеет свой тип. Тип данных определяет, что именно хранится в переменной и что с этим можно делать. Представьте, что переменные — это коробки с надписями. Надпись говорит, что лежит внутри: текст, число или что-то еще. Python сам понимает, что за тип у переменной, но программисту тоже полезно в этом разбираться.

### 1. Числовые типы

#### Целые числа (int)

Это обычные числа без дробной части. Они могут быть положительными, отрицательными и нулем:

```python
x = 10  # Положительное целое
y = -5  # Отрицательное целое
z = 0   # Ноль
```

Целые числа используются для подсчета количества предметов, индексов в списках, возрастов людей (в годах) и всего, что не требует дробной точности. Например, сколько у вас яблок, сколько студентов в группе, номер квартиры — всё это целые числа.

#### Числа с плавающей точкой (float)

Это числа с дробной частью:

```python
pi = 3.14159  # Число Пи
temperature = -2.5  # Отрицательная температура
height = 1.75  # Рост в метрах
```

Числа с плавающей точкой нужны, когда важна точность: измерения, вес, температура, деньги (хотя для денег лучше использовать специальные типы). В повседневной жизни это всё, что можно измерить с точностью до долей.

### 2. Строки (str)

Строка — это текст. Текст всегда берется в кавычки. Можно использовать одинарные или двойные кавычки — разницы нет:

```python
city = "Moscow"  # Двойные кавычки
street = 'Tverskaya'  # Одинарные кавычки
```

Если внутри текста встречаются кавычки, их нужно экранировать или использовать другой тип кавычек:

```python
text1 = "He said: 'Hello!'"  # Внутри двойных кавычек - одинарные
text2 = 'She answered: "Hi!"'  # Внутри одинарных - двойные
text3 = "Use \\ for backslash"  # Экранирование обратным слешем
```

Строки окружают нас в программировании: имена, адреса, описания, сообщения пользователю, названия файлов — всё это строки. Всё, что мы вводим через `input()`, тоже строка.

Со строками можно делать несколько полезных операций:

**Сложение (конкатенация)** — объединение строк:

```python
first = "Hello, "
second = "World!"
result = first + second  # Соединяет строки
print(result)  # Hello, World!
```

**Умножение строки на число** — повторение строки указанное количество раз:

```python
print("Ha" * 3)  # HaHaHa - повторяет строку 3 раза
```

**Длина строки** — узнать, сколько в ней символов:

```python
name = "Alexander"
print(len(name))  # 9 - количество символов
```

**Доступ по индексу** — получение отдельного символа. В Python (и многих других языках) счет символов начинается с нуля. То есть первый символ имеет индекс 0, второй — индекс 1, и так далее. Также можно использовать отрицательные индексы, чтобы считать с конца: -1 — последний символ, -2 — предпоследний и т.д.:

```python
word = "Python"
print(word[0])   # P - первый символ (индекс 0)
print(word[1])   # y - второй символ (индекс 1)
print(word[5])   # n - шестой символ (индекс 5)
print(word[-1])  # n - последний символ (отрицательный индекс)
print(word[-2])  # o - предпоследний символ
```

### 3. Булев тип (bool)

Это самый простой тип. У него всего два возможных значения: `True` (истина) и `False` (ложь):

```python
light_on = True  # Истина
door_open = False  # Ложь
```

Булевы значения чаще всего появляются в результате сравнений. Например, мы можем сравнивать числа и получать ответ "да" или "нет":

```python
x = 10
y = 5

print(x > y)    # True - 10 больше 5? Да, правда
print(x < y)    # False - 10 меньше 5? Нет, ложь
print(x == y)   # False - 10 равно 5? Нет, ложь (два знака равно!)
print(x != y)   # True - 10 не равно 5? Да, правда
print(x <= 10)  # True - 10 меньше или равно 10? Да, правда
```

Булевы значения очень важны: они используются в условиях (`if`), циклах (`while`) и везде, где программа должна принимать решение. Программа как бы спрашивает: "Верно ли это?" и получает ответ "Да" (`True`) или "Нет" (`False`).

### 4. Преобразование типов

Помните, мы говорили, что `input()` всегда возвращает строку? Что делать, если нам нужно число?

Для этого в Python есть функции преобразования типов. Это как переводчик с одного языка на другой: мы берем строку и превращаем ее в число, или наоборот.

**Преобразование в целое число (`int()`):**

```python
age_text = input("How old are you? ")  # Получаем строку
age = int(age_text)  # Преобразуем в число (целое)
print("In 10 years you will be", age + 10)  # Теперь можно складывать как числа
```

Если пользователь введет "abc" вместо числа, программа выдаст ошибку. Поэтому нужно быть уверенным, что ввод корректен, или обрабатывать ошибки (об этом позже).

**Преобразование в дробное число (`float()`):**

```python
height_text = input("Your height in meters: ")  # Получаем строку
height = float(height_text)  # Преобразуем в дробное число
print("Your height in cm:", height * 100)  # Умножаем как число
```

**Преобразование в строку (`str()`):**

Иногда это нужно, чтобы объединить число с текстом:

```python
age = 25
print("I am " + str(age) + " years old")  # Преобразуем число в строку
```

Хотя Python позволяет не использовать преобразование при `print()` с запятыми:

```python
print("I am", age, "years old")  # Можно и так, без преобразования
```

### 5. Проверка типа: функция type()

Иногда полезно узнать, к какому типу относится переменная. Для этого используется встроенная функция `type()`:

```python
x = 10
print(type(x))  # <class 'int'> - целое число

y = 3.14
print(type(y))  # <class 'float'> - дробное число

name = "Alice"
print(type(name))  # <class 'str'> - строка

is_active = True
print(type(is_active))  # <class 'bool'> - булево значение
```

Это может пригодиться, когда вы не уверены, что за данные попали в переменную, особенно при работе с пользовательским вводом или данными из внешних источников.

### 6. Простое, но важное: переменные

Переменные — это ячейки памяти, в которых мы храним данные. Можно представить переменную как коробку с ярлыком. На ярлыке написано имя переменной, а внутри лежит значение. Python сам понимает, что за тип у переменной — ему не нужно объяснять, что "в этой коробке будет лежать число". Вы просто кладете значение, а Python запоминает его тип.

В Python не нужно объявлять тип переменной заранее — он определяется автоматически в момент присваивания значения:

```python
x = 5          # Сначала это число int
x = "Hello"    # Теперь это строка str (и это нормально для Python!)
```

Имя переменной должно начинаться с буквы или символа подчеркивания, может содержать буквы, цифры и подчеркивания. Регистр важен: `name` и `Name` — это разные переменные:

```python
variable = 10
Variable = 20  # Это другая переменная!
```

Хорошие имена переменных — это те, которые понятны без пояснений. Вместо `x` лучше написать `age`, вместо `s` — `username`. Так ваш код будет легче читать и понимать.

### 7. Динамическая типизация: что это значит?

Термин "динамическая типизация" означает, что тип переменной определяется во время выполнения программы, а не во время написания кода. В статически типизированных языках (например, Java или C++) вы должны заранее сказать: "эта переменная будет хранить целое число". В Python же можно просто написать:

```python
x = 10   # x теперь целое число
x = "hi" # x теперь строка
```

Программа не выдаст ошибку. Это делает Python более гибким, но требует внимательности: если вы ожидаете число, а в переменной окажется строка, программа может упасть. Поэтому важно проверять типы, когда это критично.

## Простая программа: всё вместе

Давайте соберем всё, что мы узнали, в одну маленькую программу. Мы добавим комментарии, чтобы было понятно, что делает каждая часть:

```python
# Программа для вычисления площади прямоугольника
# Это пример использования ввода, вывода и разных типов данных

print("Rectangle Area Calculator")  # Приветствие пользователя

# Получаем данные от пользователя
# input() всегда возвращает строку (str)
width_text = input("Enter width: ")  # Строка с шириной
height_text = input("Enter height: ")  # Строка с высотой

# Преобразуем строки в числа с плавающей точкой
# Это нужно, чтобы выполнять математические операции
width = float(width_text)  # Теперь это число (float)
height = float(height_text)  # Теперь это число (float)

# Проверяем, что получилось
print("Type of width:", type(width))  # Выведет: <class 'float'>
print("Type of height:", type(height))  # Выведет: <class 'float'>

# Вычисляем площадь (умножаем два числа)
# Результат тоже будет числом (float)
area = width * height

# Выводим результат
# Мы можем объединять строки и числа через запятую в print()
print("Area of rectangle is", area)  # Выводит результат
```

## Важно запомнить

1. **Комментарии (`#`)** — игнорируются Python, нужны для пояснения кода
2. **`print()`** — выводит информацию на экран
3. **`input()`** — получает информацию от пользователя (всегда возвращает строку)
4. **Целые числа (`int`)** — без дробной части (например, 10, -5, 0)
5. **Дробные числа (`float`)** — с дробной частью (например, 3.14, -2.5)
6. **Строки (`str`)** — текст в кавычках (например, "Hello")
7. **Булевы значения (`bool`)** — `True` или `False`
8. **`type()`** — показывает тип переменной
9. **Преобразование типов** — `int()`, `float()`, `str()` меняют тип данных
10. **Переменные** — не требуют объявления типа, тип определяется автоматически (динамическая типизация)

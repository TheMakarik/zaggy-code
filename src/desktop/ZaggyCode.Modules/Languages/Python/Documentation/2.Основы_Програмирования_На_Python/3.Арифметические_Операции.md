# Арифметические операции

## Введение

В прошлой статье мы познакомились с основами ввода, вывода и типами данных. Теперь пришло время научиться делать с этими данными что-то полезное — вычислять, сравнивать, преобразовывать. Арифметика — это фундамент, на котором строится любая логика в программировании. Без нее невозможно написать ни один калькулятор, ни одну игру, ни одно приложение для работы с данными. В этой статье мы подробно разберем все арифметические операции в Python, их особенности и подводные камни. Также мы посмотрим, как арифметика работает не только с числами, но и со строками и булевыми значениями.

## Базовые арифметические операции

В Python есть все привычные нам математические операции. Они работают так же, как в обычной математике, с небольшими нюансами, о которых мы поговорим.

### Сложение (+)

Операция сложения работает с числами любого типа:

```python
a = 10
b = 5
result = a + b
print(result)  # 15
```

Сложение также работает со строками (объединяет их), но это уже не арифметика, а конкатенация:

```python
text = "Hello" + " " + "World"
print(text)  # Hello World
```

А вот со сложением булевых значений есть интересный нюанс. В Python булевы значения `True` и `False` на самом деле являются подтипами целых чисел. `True` эквивалентен 1, а `False` эквивалентен 0. Поэтому их можно складывать:

```python
print(True + True)    # 2 (1 + 1)
print(True + False)   # 1 (1 + 0)
print(False + False)  # 0 (0 + 0)
print(10 + True)      # 11 (10 + 1)
print(10 + False)     # 10 (10 + 0)
```

### Вычитание (-)

С вычитанием всё просто:

```python
a = 10
b = 5
result = a - b
print(result)  # 5
```

Можно получать отрицательные числа:

```python
a = 5
b = 10
result = a - b
print(result)  # -5
```

Вычитание работает и с булевыми значениями:

```python
print(True - False)   # 1 (1 - 0)
print(False - True)   # -1 (0 - 1)
print(10 - True)      # 9 (10 - 1)
```

Важно: вычитание НЕ работает со строками. Попытка вычесть одну строку из другой вызовет ошибку.

### Умножение (*)

Умножение чисел:

```python
a = 10
b = 5
result = a * b
print(result)  # 50
```

Умножение строки на число повторяет строку указанное количество раз. Это одна из самых удобных фишек Python:

```python
print("Ha" * 3)       # HaHaHa
print("=" * 20)       # ====================
print("-" * 10)       # ----------
```

Умножение строки на ноль дает пустую строку:

```python
print("Hello" * 0)    # (пустая строка)
```

Умножение строки на дробное число вызовет ошибку.

Умножение с булевыми значениями:

```python
print(True * 10)      # 10 (1 * 10)
print(False * 10)     # 0 (0 * 10)
print(True * True)    # 1 (1 * 1)
print(True * "Ha")    # Ha (строка повторяется 1 раз)
print(False * "Ha")   # (пустая строка, повторяется 0 раз)
```

### Деление (/)

В Python есть два вида деления, и это важно запомнить. Обычное деление (`/`) всегда возвращает дробное число, даже если результат целый:

```python
a = 10
b = 5
result = a / b
print(result)  # 5.0 (дробное число, а не целое!)
```

```python
a = 7
b = 2
result = a / b
print(result)  # 3.5
```

Это отличает Python от многих других языков, где деление целых чисел дает целый результат.

Деление булевых значений тоже работает:

```python
print(True / True)    # 1.0 (1 / 1)
print(10 / True)      # 10.0
```

Деление на `False` вызовет ошибку, потому что это деление на ноль.

### Целочисленное деление (//)

Иногда нужно получить только целую часть от деления, отбросив дробную. Для этого используется оператор `//` (два слеша). Он возвращает целое число:

```python
a = 7
b = 2
result = a // b
print(result)  # 3 (целая часть от деления 7 на 2)
```

Важно: целочисленное деление всегда округляет вниз (в сторону минус бесконечности), даже для отрицательных чисел:

```python
print(7 // 2)   # 3
print(-7 // 2)  # -4 (не -3!)
```

Это может быть неожиданным, но так работает математика округления в Python.

Целочисленное деление с булевыми значениями:

```python
print(10 // True)   # 10
```

Деление на `False` вызовет ошибку.

### Остаток от деления (%)

Оператор `%` возвращает остаток от деления:

```python
a = 7
b = 2
result = a % b
print(result)  # 1 (остаток от деления 7 на 2)
```

```python
a = 10
b = 3
result = a % b
print(result)  # 1 (10 = 3*3 + 1)
```

Остаток от деления часто используют для проверки четности чисел (число четное, если `x % 2 == 0`), для работы с циклами (например, чтобы определить, наступила ли каждая 5-я итерация), для преобразования времени и многих других задач.

Остаток от деления с булевыми значениями:

```python
print(10 % True)    # 0 (10 % 1)
```

Деление на `False` вызовет ошибку.

### Возведение в степень (**)

Для возведения числа в степень используется оператор `**`:

```python
a = 2
b = 3
result = a ** b
print(result)  # 8 (2 в степени 3)
```

```python
print(3 ** 4)   # 81
print(10 ** 2)  # 100
```

Можно возводить в дробную степень (извлекать корни):

```python
print(9 ** 0.5)      # 3.0 (квадратный корень из 9)
print(8 ** (1/3))    # 2.0 (кубический корень из 8)
```

Возведение в степень с булевыми значениями:

```python
print(True ** True)   # 1
print(False ** True)  # 0 (0 в степени 1)
print(True ** False)  # 1 (1 в степени 0)
print(2 ** True)      # 2
print(2 ** False)     # 1 (любое число в степени 0 равно 1)
```

## Приоритет операций

В Python, как и в математике, операции имеют приоритет. Сначала выполняются действия в скобках, затем возведение в степень, потом умножение и деление, и в последнюю очередь сложение и вычитание:

```python
result = 2 + 3 * 4
print(result)  # 14, а не 20 (сначала умножение)
```

Чтобы изменить порядок, используйте скобки:

```python
result = (2 + 3) * 4
print(result)  # 20 (сначала сложение в скобках)
```

Полный порядок приоритета:
1. `**` — возведение в степень
2. `*`, `/`, `//`, `%` — умножение, деление, целочисленное деление, остаток
3. `+`, `-` — сложение и вычитание

Операции с одинаковым приоритетом выполняются слева направо:

```python
result = 10 - 5 - 2
print(result)  # 3 (сначала 10 - 5 = 5, потом 5 - 2 = 3)
```

## Арифметика с разными типами

В Python можно смешивать целые числа и дробные. Результат всегда будет дробным числом:

```python
a = 10      # целое число
b = 3.5     # дробное число
result = a + b
print(result)  # 13.5 (дробное число)
```

Любая операция, где участвует хотя бы одно дробное число, возвращает дробное число:

```python
print(10 / 2)     # 5.0 (деление всегда возвращает дробное)
print(10 // 2)    # 5 (целочисленное деление)
print(10.0 // 2)  # 5.0 (если участвует дробное, результат дробный)
```

Смешивание чисел с булевыми значениями:

```python
x = 10 + True   # 11
y = 5 * False   # 0
z = 7 - True    # 6
```

## Сравнение чисел и булевых значений

Булевы значения можно сравнивать с числами:

```python
print(True == 1)   # True
print(False == 0)  # True
print(True == 2)   # False
print(False == 0.0)  # True
```

## Оператор присваивания с вычислением

В Python есть сокращенные формы записи, которые совмещают присваивание и арифметическую операцию. Это делает код короче и читаемее:

```python
x = 10
x += 5   # То же самое, что x = x + 5
print(x)  # 15

x -= 3   # То же самое, что x = x - 3
print(x)  # 12

x *= 2   # То же самое, что x = x * 2
print(x)  # 24

x /= 4   # То же самое, что x = x / 4
print(x)  # 6.0

x //= 2  # То же самое, что x = x // 2
print(x)  # 3.0

x %= 2   # То же самое, что x = x % 2
print(x)  # 1.0

x **= 3  # То же самое, что x = x ** 3
print(x)  # 1.0
```

Такие сокращения удобны в циклах и при накоплении сумм. Они работают и с булевыми значениями, и со строками:

```python
text = "Hello"
text += " World"   # text = text + " World"
print(text)        # Hello World

text *= 2          # text = text * 2
print(text)        # Hello WorldHello World

flag = True
flag += True       # flag = True + True
print(flag)        # 2 (True стал числом 2)
```

## Проблемы арифметики с дробными числами

Важно помнить, что компьютеры хранят числа не так, как мы привыкли. Десятичные дроби в двоичной системе счисления часто дают неточные результаты:

```python
print(0.1 + 0.2)  # 0.30000000000000004 (а не 0.3)
```

Это не ошибка Python, а особенность представления чисел в компьютере. Такое есть во всех языках программирования. Если вам нужна высокая точность (например, при работе с деньгами), используйте специальные типы данных или целые числа, считая в копейках. Для большинства повседневных задач эта погрешность не критична.

Сравнивать дробные числа на равенство тоже нужно аккуратно. Лучше сравнивать с допустимой погрешностью:

```python
# Так делать не рекомендуется:
if 0.1 + 0.2 == 0.3:
    print("Equal")  # Это не выполнится!

# Лучше сравнивать с допустимой погрешностью:
if (0.1 + 0.2) - 0.3 < 0.0001:
    print("Equal")  # Это выполнится
```

## Практические примеры

Давайте посмотрим, как арифметика используется в реальных задачах:

### Калькулятор чаевых

```python
# Программа для расчета чаевых в ресторане

print("Tip Calculator")

# Получаем сумму счета
bill_text = input("Enter bill amount: ")
bill = float(bill_text)

# Получаем процент чаевых
tip_percent_text = input("Enter tip percentage (e.g., 15): ")
tip_percent = float(tip_percent_text)

# Рассчитываем чаевые и итоговую сумму
tip_amount = bill * (tip_percent / 100)
total = bill + tip_amount

print("Bill:", bill)
print("Tip:", tip_amount, "(", tip_percent, "%)")
print("Total:", total)
```

### Определение четности с помощью остатка

```python
# Проверяем четность числа с использованием остатка от деления

number_text = input("Enter a number: ")
number = int(number_text)

# Используем оператор % (остаток от деления)
is_even = number % 2 == 0  # True если четное, False если нечетное

print("Number is even:", is_even)
```

### Калькулятор времени

```python
# Преобразование минут в часы и минуты

minutes_text = input("Enter minutes: ")
total_minutes = int(minutes_text)

hours = total_minutes // 60  # Целочисленное деление
minutes = total_minutes % 60   # Остаток от деления

print(total_minutes, "minutes =", hours, "hours and", minutes, "minutes")
```

### Подсчет стоимости покупок

```python
# Программа для подсчета общей стоимости

print("Shopping Calculator")

# Получаем количество товаров
items_text = input("Enter number of items: ")
items = int(items_text)

# Получаем цену за один товар
price_text = input("Enter price per item: ")
price = float(price_text)

# Общая стоимость
total = items * price

print("Total cost:", total)
```

## Важно запомнить

1. **Сложение (`+`)** — работает с числами, строками (объединение) и булевыми значениями
2. **Вычитание (`-`)** — только с числами и булевыми, НЕ работает со строками
3. **Умножение (`*`)** — работает с числами, строками (повторение) и булевыми
4. **Деление (`/`)** — всегда возвращает дробное число, работает с числами и булевыми
5. **Целочисленное деление (`//`)** — возвращает целую часть, округляет вниз
6. **Остаток от деления (`%`)** — возвращает остаток, часто используется для проверки четности
7. **Возведение в степень (`**`)** — работает с числами и булевыми
8. **Булевы значения** — `True = 1`, `False = 0`, могут участвовать в арифметике
9. **Приоритет операций** — как в математике: скобки, степень, умножение/деление, сложение/вычитание
10. **Смешивание типов** — целое + дробное дает дробное, булево ведет себя как число
11. **Точность дробных чисел** — не сравнивайте дробные числа на равенство напрямую
12. **Сокращенные операции** — `+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `**=` работают с числами, строками и булевыми
